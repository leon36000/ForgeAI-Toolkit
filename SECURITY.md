# Politique de sécurité

## Versions prises en charge

Le projet ForgeAI Toolkit n'a pas encore de version publiée (aucun paquet publié sur PyPI, palier RC1 en cours). Seul l'état actuel de la branche principale (`main`) est maintenu et reçoit les correctifs.

| Version | Prise en charge |
| :--- | :--- |
| `main` | Oui |
| Releases antérieures | Non (aucune release publiée) |

## Signalement d'une vulnérabilité

Pour signaler une vulnérabilité de sécurité :

1. Utilisez exclusivement le mécanisme natif GitHub de signalement privé sur ce dépôt : rendez-vous dans l'onglet **Security** puis cliquez sur **Report a vulnerability**.
2. Ne divulguez aucun détail technique publiquement (via une Issue publique ou une Pull Request) avant qu'un correctif n'ait été validé.
3. Incluez dans votre signalement une description détaillée, les étapes de reproduction et l'impact estimé.

Le traitement du signalement et les échanges associés s'effectuent directement via le canal privé fourni par GitHub.
