# manifests/ — le plan comme données (§2 du plan maître)

Les modèles lisent ces manifestes, jamais la prose. Produits en Phase A
(consolidation MiMo), maintenus à chaque merge :

- `roles.yaml` — équipe, rôles Phase A/B, routes bridge, règles de revue (présent)
- `routes.yaml` — routes gateway testées + statut de connexion (généré à l'étape 3)
- `phases.yaml` — phases d'exécution et fonctionnalités livrables (Phase A)
- `bricks.yaml` — catalogue des briques déployables (Phase A)
- `gates.yaml` — gates déterministes et seuils (Phase A)
