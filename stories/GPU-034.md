## Finding I1 — le seuil `>= 8192` MiB rejette les GPU 8 Go réels
`planner/profile.py::_usable` exige `vram_mb >= 8192` pour NVIDIA (et le même seuil pour
AMD). Mesuré **deux fois indépendamment** sur le même matériel (pc2, RTX 4070 Laptop) :
`gpu-feature-discovery` (l'outil NVIDIA lui-même) rapporte `nvidia.com/gpu.memory = 8188`,
et `nvidia-smi` confirme `8188 MiB`. La VRAM utile est toujours inférieure à la capacité
nominale (réservations firmware) : un seuil d'égalité stricte sur une puissance de 2 ne
peut jamais être atteint par une carte de cette classe — la classe de GPU la plus répandue
en portable est rejetée.

## Finding I2 — la garde HW-010 ne protège plus dès qu'un autre vendor est utilisable
`derive_profile` ne lève `ProfileError` (HW-010) que si `not usable` (AUCUN GPU utilisable
sur toute la machine). Sur une machine hybride (ex. pc2 : NVIDIA cassé `[unqualified]` +
Intel utilisable), `usable` n'est pas vide → la boucle retourne `minimal-gpu-intel` et le
garde-fou n'est **jamais atteint** : le NVIDIA cassé disparaît **silencieusement**, sans
aucun signal. C'est le comportement correct pour le CHOIX du profil (déployer sur le GPU qui
fonctionne est la bonne décision) — mais l'absence de signal contredit l'intention de HW-010
(« ne jamais faire disparaître un GPU cassé sans le dire »). Portée : toute machine hybride
(cas fréquent sur laptop gaming : iGPU/dGPU AMD/Intel + dGPU NVIDIA).

## Décision
1. **I1** : abaisser le seuil des GPU dédiés « classe 8 Go » (NVIDIA et AMD, qui partagent
   le même magic number `8192`) à une valeur qui admet la mesure réelle avec marge de
   sécurité, sans risquer d'admettre une carte réellement plus petite. Introduire une
   constante nommée et documentée (measured evidence = 8188 MiB, RTX 4070 Laptop, pc2,
   LAB-033I). Le seuil Intel (`>= 4096 MiB`) n'est PAS touché (aucune évidence de problème).
2. **I2** : NE PAS changer le profil retourné dans le cas hybride (rester sur le vendor
   utilisable est la bonne décision produit). Rendre le contournement **visible** :
   extraire une fonction pure additive qui détecte les GPU non-qualifiés ignorés, et
   appeler cette fonction au point d'entrée CLI (`cli.py`, wizard) pour imprimer un
   avertissement — sans bloquer le déploiement sur le vendor qui fonctionne. Aucun
   changement de signature de `derive_profile` (reste `-> str`, tous les appelants
   existants — `cli.py`, `network/remote_probe.py` — restent inchangés).
