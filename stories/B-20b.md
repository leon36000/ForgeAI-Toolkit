# B-20b — Brancher le metering au gateway (chemins RAG + probe)

Implémentation du branchement décidé par l'ADR B-20 (voir `stories/B-20.md`, décision
architecte + addendum B-20b sur le journal `exact=false`). Dépend de B-20a (fondation
`budget.py` : verrou, `extraire_tokens`, `QuotaAtteint`, `check`/`record`/`status`).

## Contexte

B-20a a livré la fondation SANS toucher aucun chemin de production. B-20b instrumente les deux
seuls sites où la réponse LLM existe (ADR §1) — le chemin RAG (`hardened.py`, appel
`_post_bearer`) et le chemin probe (`probe.py`, Protocol `Transport`) — sans introduire de point
commun (les deux graphes d'appel sont disjoints par construction).

Écart de fondation constaté et comblé : B-20a produisait le flag `exact` (`extraire_tokens`) mais
AUCUN journal ne le persistait, alors que l'ADR §3/§6/§7 en fait un critère de B-20b. Le journal
`meter-events.jsonl` a donc été ajouté à `budget.py` (addendum architecte à l'ADR).

## Décision (appliquée)

1. **Journal `exact=false`** (`budget.py`) : `record()` gagne `(*, exact=True, motif=None)` —
   extension additive. Anomalie `exact=False` → 1 ligne dans `meter-events.jsonl` (fichier frère
   append-only, sous le même `file_lock`, horloge injectable) ; le compteur `budgets.json` n'est
   pas modifié. Gardes `ValueError` (bug d'appelant, distinct de `BudgetError`).
2. **Chemin probe** : `MeteredTransport(inner, tracker, agent="probe")` décore le Protocol
   `Transport` — `check` pré-dispatch (zéro émission sur COUPURE), transparent sur le fil,
   comptabilisation après (status 0 → `motif="timeout"`, sinon `extraire_tokens` sur le corps).
   Injection opt-in via le paramètre `transport` existant.
3. **Chemin RAG** : `HardenedRagClient` gagne `agent="rag"` et `tracker: BudgetTracker | None =
   None` (metering OPT-IN — `tracker=None` = comportement B-24 strictement inchangé). Quand un
   tracker est fourni : `check` avant `_post_bearer`, timeout → journal `motif="timeout"` puis
   re-raise (§7.1, aucun double comptage), sinon `extraire_tokens` + `record`.
4. **Garde CI §7.4** : filet coopératif interdisant qu'un `.py` hors des sites mesurés référence
   `chat/completions`. Explicitement non-preuve-de-sécurité (l'URL peut être construite
   autrement) : rend tout nouveau site d'émission visible. La LOGIQUE vit dans
   `src/forgeai/models/metering_guard.py` (couverte à 100 % par `tests/test_metering_guard.py`) ;
   `scripts/check_metering_sites.py` n'en est qu'un lanceur CLI mince (job gates `metering-sites`,
   exclu de la couverture Sonar comme les scripts de preuve). L'allowlist exonère les deux sites
   instrumentés ET le module de la garde lui-même (qui DÉFINIT le marqueur — une référence, pas
   une émission).

## Critères d'acceptation (tous mesurés verts)

- [x] `record(agent, N)` positionnel inchangé ; 24 tests B-20a intacts.
- [x] anomalie → 1 ligne `meter-events.jsonl` aux 5 champs `{ts, agent, tokens, exact, motif}`.
- [x] `MeteredTransport` : usage présent → compteur +N ; COUPURE → `QuotaAtteint` avant tout
      `post` (espion : zéro émission) ; sans usage → journal `usage_absent` ; status 0 → journal
      `timeout` ; retour `inner` inchangé.
- [x] `HardenedRagClient` mesuré : usage → +N sur `"rag"` ; COUPURE → lève avant `_post_bearer` ;
      sans usage → `usage_absent` ; timeout → `timeout` puis propage ; `tracker=None` → aucun
      metering (28 tests RAG existants intacts).
- [x] garde CI : arbre réel propre ; détecte un site non autorisé ; job `metering-sites`.
- [x] suite complète 1386 passed ; 8 mutations tuées (2 budget, 2 probe, 3 hardened, 1 garde).

## Écart résiduel (à ne pas masquer)

Le metering RAG/probe est OPT-IN : cette story livre le MÉCANISME (mesuré par stubs). Le câblage
du `tracker` dans les points de construction de production (serveur web, CLI) — pour que le
metering soit ACTIF par défaut en prod — n'est pas dans ce périmètre ; c'est un branchement
ultérieur (B-20c), sans lequel les compteurs restent à zéro en production. Le journal
`meter-events.jsonl` est par-hôte (ADR §7.3), non rotaté (ADR §5 addendum), non autoritaire.
