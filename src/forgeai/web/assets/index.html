Modèles IA

Tous les modèles open-weight — petits, moyens, gros — déployables sur n'importe quel nœud du réseau. Aucun n'est masqué : choisissez librement, chaque nœud cible affiche s'il peut le servir.

Modèles cloud & clés API (optionnel)

Routes modèle cloud — test de connexion réel obligatoire ; la clé est scellée au coffre, seule l'empreinte est conservée.

La clé transite en mémoire vers le serveur local (127.0.0.1) puis est scellée au coffre chiffré — jamais écrite en clair, jamais réaffichée.

Briques additionnelles

Catalogue complet, classé par sphère. Les briques du stack sont pré-cochées ; le châssis commun est verrouillé.

Nœuds — cluster multi-machines

Ajoutez un nœud avec son IP, utilisateur et mot de passe — utilisé une seule fois au bootstrap, puis bascule sur clé ed25519. Jamais écrit sur disque.

🔑 Le mot de passe sert une seule fois : installation de la clé publique, bascule immédiate sur ed25519, puis seule l'empreinte est journalisée au registre.
