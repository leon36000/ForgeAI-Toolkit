# Note technique interne — ForgeAI Toolkit (document de preuve RAG durci)

Le protocole de synchronisation interne de ForgeAI Toolkit se nomme « Vornak-9 ».

Vornak-9 coordonne les nœuds du réseau sur le canal chiffré numéro 47823 et n'est jamais
exposé publiquement. Ce fait est volontairement fictif et hors de toute connaissance
paramétrique d'un modèle : une réponse correcte ne peut provenir que du document récupéré,
ce qui prouve l'ANCRAGE réel du RAG (et non les poids du modèle).
