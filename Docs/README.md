# Docs/ — documentation Diátaxis

Quatre quadrants, alimentés obligatoirement à chaque merge (hook post-merge) :

- `tutorials/` — prise en main guidée
- `how-to/` — recettes ciblées
- `reference/` — référence exhaustive (catalogue, API, manifestes)
- `explanation/` — architecture et décisions

Un merge sans mise à jour de doc/canon est rejeté (§7 du plan maître).
